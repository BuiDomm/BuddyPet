# Archived: production `.riv` workflow

> This workflow is not part of the BuddyPet release plan. Runtime `.riv` export
> was removed to keep development and distribution costs at zero. The current
> pipeline is documented in `docs/ASSET_PIPELINE.md`.

The four `.riv` files are exported runtime artifacts from **Rive Editor**. They
are not generated by the React runtime and they are not interchangeable with a
PNG, SVG, GIF, or video. BuddyPet may start from vector artwork, but the
installed app renders the final `.riv` rig.

## 1. Produce animation-ready character masters

An illustrator redraws each approved mascot as clean, separated vector parts.
Use SVG/AI as the **source handed to the animator**, not as the runtime asset.

Required separated parts:

- head, muzzle, jaw/mouth shapes, eyes/pupils/eyelids and brows;
- torso/hips, upper and lower limbs, paws/hooves and foot contact shapes;
- ears, tail, beard/hair, jersey front/back and contact shadow;
- prop layers such as ball, paper scrap, card, sticky note and particles;
- dedicated left/right jersey artwork so `10` and `7` are never mirrored.

Each master also needs a neutral pose, front/three-quarter turnaround, color
palette, expression sheet, and the approved proportions. Flattened generated
PNGs can be used as visual reference only; they should be redrawn before the
production rig.

## 2. Rig and animate in Rive Editor

A Rive character animator imports the separated art and creates:

- the bone hierarchy, mesh weights, foot/paw IK and edge-contact constraints;
- secondary motion for ears, tail, beard, jersey and props;
- two entrances, four idles, walk, run, turn, three signature pranks, click,
  cry/jump-away, pet, drag/wriggle/drop and two exits;
- cubic easing, anticipation, overshoot, squash/stretch and short blended
  transitions so poses do not snap;
- the `BuddyDirector` state machine and every input in
  [RIVE_ANIMATOR_BRIEF.md](./RIVE_ANIMATOR_BRIEF.md);
- General Events placed on the exact visual frame for sound/effect sync.

Required shared event names:

`footstepLeft`, `footstepRight`, `clothRustle`, `speciesCall`, `whoosh`,
`impact`, `bite`, `release`, `skid`, `land`, `victory`, and `effect-clear`.

Action-specific markers in `public/content/actions.v1.json` remain required.
The animator can add more markers, but must not rename the contract markers.

## 3. Review inside the real desktop shell

Editor preview alone is not acceptance. Every candidate rig is tested in the
transparent macOS and Windows pet windows at 100%, Retina/200%, mixed DPI and
on both screen edges. The review checks:

- grounded feet with no sliding during native-window travel;
- no clipping during jumps, neck stretch, tail motion or drag;
- 55+ FPS, clean state blending and no black/opaque background;
- animation markers aligned with footsteps, mouth calls, impact and landing;
- click, hold, drag, second-click exit and Reduce Motion behavior;
- hit-mask alignment throughout extreme poses.

## 4. Export and handoff

The animator uses **Publish → Export for runtime** and supplies:

| Runtime file | Artboard | State machine |
|---|---|---|
| `goat10.riv` | `Goat10` | `BuddyDirector` |
| `camel7.riv` | `Camel7` | `BuddyDirector` |
| `meme-cat.riv` | `MemeCat` | `BuddyDirector` |
| `shiba.riv` | `ShibaInu` | `BuddyDirector` |

The handoff also includes edit access to the source Rive project, the layered
illustration sources, ownership/license confirmation and a short preview video
of every state. Exported files go into `src/assets/rive`; then run:

```text
npm run check:rive:strict
npm test
npm run tauri build -- --debug
```

BuddyPet already routes actions into these rigs and listens for their events.
Once the four binaries exist, no PNG/SVG fallback is shown for a valid rig.

## Who or what is actually required

- One character illustrator for clean layered masters.
- One animator who has shipped interactive Rive character rigs, not only
  After Effects/Lottie animations.
- A Rive workspace with runtime export and source-project access.
- BuddyPet repository access or this exact contract document.

No Codex skill or connector can replace the Rive Editor authoring work. Useful
support plugins are **Creative Production** for art-production coordination,
**Figma** when layered masters live in Figma, and **Build macOS Apps** for native
overlay validation. A Rive-experienced animator remains the critical input.
